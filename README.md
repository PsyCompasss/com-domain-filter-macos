# COM域名筛选器

这是一个只面向 macOS 的 Python 桌面软件。它通过可排序的“固定文字、常用规律、自定义规律、不限随机”组合块生成 `.com` 域名，在 Cloudflare Registrar 或阿里云万网页面逐个查询，只把“名称完全一致且可注册”的结果写入一个 Excel 文件。

当前版本：`v1.4.0`（Apple 芯片 Mac）

## 使用方法

1. 打开“COM域名筛选器”。
2. 在“生成规则”中勾选允许使用的字母、数字和半角连字符 `-`。连字符不会出现在域名开头或结尾；下划线 `_` 不是合法的普通 `.com` 域名字符，因此不提供。
3. 依次添加组合块并用左右按钮调整位置。常用规律和自定义规律可以互相切换；自定义规律可填写 `ABCDDDD`、`ABCBA` 等任意占位结构。
4. “不限随机”块可以单独填写随机位数。可选择每个规律块独立抽取字符，或让所有规律块中的 `A、B、C` 分别共用同一字符。
5. 在“运行设置”中输入查询间隔、页面异常重试间隔（秒）、停止条件和 Excel 保存路径。
6. 在“运行设置”中选择 Cloudflare 或阿里云万网。网站名称可以直接输入，填写网址后点“添加/保存”即可保存到列表。
7. 先点击“打开/连接 Chrome”，确认顶部显示“准备就绪”，再点击“开始查询”。只有前一个按钮可以打开 Chrome；“开始查询”只连接已经准备好的窗口。查询时只使用名称部分，不把 `.com` 填入网站搜索框，然后按完整 `.com` 结果进行精确比对。

## 验证与后台运行

- 软件使用 Mac 已安装的 Google Chrome，不再附带自动测试版 Chromium，也不会操作你原有的 Chrome 标签页。
- 专用 Chrome 窗口不会自动最小化、置前、移动或关闭。你可以手动最小化它，查询会继续运行。
- 点击软件的“停止”按钮只会停止查询，专用 Chrome 窗口会保持打开；需要关闭时由你手动关闭。
- 修改规则后再次点击“开始查询”时，软件只会重新连接已经确认的专用 Chrome，不会在“开始查询”阶段另开窗口。
- 如果 Chrome 启动较慢，软件会持续沿用会话中记录的同一个调试端口；即使 Chrome 进程或 PID 暂时还未出现，也不会在重试时不断更换端口。调试端点已经可用时，macOS 暂时查不到 PID 也不会阻止连接。
- 普通的页面空白、结果加载超时或临时网络故障会按你填写的秒数自动刷新；同一个域名连续失败3次会自动跳过，不会弹窗打扰。只有网站明确要求真人验证时才需要你处理。
- 查询网站可能随时要求安全验证或暂时拒绝自动查询。
- 软件检测到验证、超时或Cloudflare错误页时会暂停并弹窗。
- 请在弹出的系统 Chrome 窗口中完成验证。若验证持续循环，请停止任务，稍后重试，并检查代理、VPN、浏览器扩展或网络。
- 软件不会自动破解或绕过验证码。
- 如果连续两次遇到验证，软件会停止当前任务，不再让你反复勾选。

## 保存内容

- Excel只记录完全一致且可注册的 `.com` 域名。
- 软件内部会记录已经测试过的域名，用于去重和断点续查。
- 内部状态保存在 `~/Library/Application Support/COM域名筛选器/`。
- 更换Excel路径时，软件会把内部已经找到的可注册结果同步到新文件。

## 注意事项

- 当前适配 `https://domains.cloudflare.com/` 和 `https://wanwang.aliyun.com/domain`。其他网站可以保存到列表，但必须先编写对应适配器才能开始查询。
- 查询网站的页面结构、查询接口或反自动化策略发生变化时，软件可能需要更新。
- 查询间隔过短更容易触发验证或临时限制。
- 软件只检查可注册状态，不会购买、注册或提交付款。
- 启动和浏览器错误会记录在 `~/Library/Application Support/COM域名筛选器/app.log`。

## 源码运行

需要 Python 3.12：

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```
