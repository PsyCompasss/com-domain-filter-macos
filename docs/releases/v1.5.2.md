# COM域名筛选器 v1.5.2

## 新增功能

- 新增“已查询记录”页面，可查看、搜索、筛选和导出全部查询历史。
- 支持删除选中记录或清空历史，删除后的域名可以重新查询。
- 已查询记录可以单独导出为 Excel。
- 暂停期间修改域名组合规则后，继续任务会从下一条域名开始采用新规则。
- 更换为铺满 macOS 图标底板的新版应用图标。

## 万网结果判断改进

- 只有发现名称完全一致的 `.com` 条目，并确认它是“可注册”或“已注册/正在出售”后，才会继续下一条。
- 精确 `.com` 位于第二行、第三行或更靠后时也会继续等待并识别。
- 万网页面短暂显示“暂无内容”时不会立即误判。
- 页面临时空白或加载失败时，会按用户设置的刷新间隔自动重试。
- 修复万网把“已注册”放进域名标题后，程序把 `rbcf.com` 错读成 `rbcf已注册`、最终记为“查询失败”的问题。
- 推荐域名（例如 `myrbcf.com`）不会被误判为用户查询的 `rbcf.com`。

## 验证情况

- 55 项自动测试全部通过。
- 已使用万网真实页面的“域名 + 后缀 + 已注册”DOM 结构验证名称提取。
- macOS Apple Silicon 安装包已完成构建和代码签名完整性检查。

> 安装包采用本地临时签名，未进行 Apple Developer ID 公证。首次打开时，macOS 可能仍会要求用户确认。
