# 全网域名筛选器 v1.8.3

## 中文

v1.8.3 将软件从单一 `.com` 查询扩展为多后缀域名筛选，并保留严格的完整域名核对机制。

### 新功能

- 新增后缀池，可按常用、其他公开、国家/地区、国际化和完整 IANA 分类选择多个后缀。
- 同一名称只提交一次，并从同一结果页中分别确认所有已选后缀。
- 新增 TXT、CSV 和 Excel 域名导入，按导入顺序查询。
- 新增“至少包含”字符次数限制。
- 固定文字、常用规律和自定义规律支持随机插入名称前、中、后部。
- 国际化后缀以 `.中国` 等可读形式展示，内部自动完成 IDN 转换。

### 稳定性与判断修复

- 万网页面稳定后才开始检查和分段滚动，避免页面未加载完成就直接拉到底。
- 完整域名必须与目标一致，推荐域名不能再影响目标判断。
- 已注册状态优先于可注册状态，处理结果短暂出现后消失的页面情况。
- 页面缺少某个已选后缀时，明确记录“未找到该后缀结果”，不会猜测为可注册或已注册。
- 暂停期间修改规则或后缀池，继续后从下一组查询采用最新设置。

### 界面与数据

- 软件更名为“全网域名筛选器”。
- 新增已查询记录查看、筛选、删除和 Excel 导出；删除历史后可重新查询。
- 导入模式保留生成规则界面，并将暂不可用的控件置灰；清空导入后自动恢复。
- 优化组合方块、快捷模板、结果页和图标展示。

> 当前 macOS 安装包采用 ad-hoc 临时签名，尚未经过 Apple Developer ID 公证。首次打开时可能需要在 Finder 中右键选择“打开”。

## English

Version 1.8.3 expands the app from `.com`-only checks to multi-TLD filtering while preserving strict exact-domain verification.

### New

- A TLD pool grouped into common, public, country/region, internationalized, and full IANA catalogs.
- One name query can classify all selected suffixes shown on the same registrar result page.
- TXT, CSV, and Excel domain imports with ordered processing.
- Minimum character occurrence constraints.
- Random-position insertion for fixed text, presets, and custom patterns.
- Human-readable IDN suffixes such as `.中国`, with automatic internal IDN conversion.

### Reliability

- Wanwang checks and bounded scrolling begin only after the page has stabilized.
- Exact full-domain matching prevents recommendation cards from affecting the target result.
- Explicit registered evidence takes precedence over availability evidence, including transient result cards.
- Missing selected suffixes are recorded as “result not found” and are never guessed as available or registered.
- Rule and TLD changes made while paused apply to the next query group after resuming.

### UI and data

- The app is renamed to **Universal Domain Filter / 全网域名筛选器**.
- Query history can be viewed, filtered, deleted, and exported to Excel; deleted history can be queried again.
- Import mode keeps the rule builder visible with unavailable controls disabled, then restores them after the import is cleared.
- Refined builder cards, quick templates, results layout, and app icon presentation.

> The macOS package is ad-hoc signed and is not notarized with an Apple Developer ID. You may need to right-click the app in Finder and choose **Open** on first launch.
